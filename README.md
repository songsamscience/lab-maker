# 송쌤과학 가상실험실 만들기 (학생용)

중학생이 AI에게 붙여 넣을 프롬프트를 골라서 과학 게임과 가상실험실 초안을 만드는 곳입니다.

**바로 가기:** https://songsamscience.github.io/lab-maker/

## 무엇을 할 수 있나요
1. **게임으로 몸풀기** — 추천 게임 15개 중 하나를 고르거나, 내가 원하는 게임 제목을 적으면 프롬프트가 나옵니다.
2. **실험실 계획 세우기** — 탐구형 · 실험형 · 게임형 중에서 고르고 계획 → 설계 → 방향 → 규칙을 정하면 초안 프롬프트가 완성됩니다. 학년과 단원(초등 ~ 고1 통합과학, 교과 밖 주제는 자유 탐구)을 고를 수 있고, 「주기율표 게임으로 따라 해 보기」 연습이 들어 있습니다.
3. **만들고 고치기** — AI마다 실행하는 법, 실행해 보고 확인하기, 넣고 싶은 기능 10가지 고르기, 고쳐 달라고 말하는 문장, 실습 기록지 저장을 모았습니다.
4. **웹에 올리기** — AI마다 HTML 파일로 저장하는 법과, Netlify Drop · GitHub Pages · Cloudflare 중 하나를 골라 웹에 올리는 순서를 안내합니다.

프롬프트는 복사하거나 txt 파일로 저장할 수 있고, 고른 AI(Copilot · Gemini · ChatGPT · Claude)에 맞게 길이와 결과물 받는 방법이 바뀝니다.

## 알아 두기
- 한 파일(`index.html`)로 동작하며, 입력한 내용은 브라우저에만 저장됩니다. 실습 기록지의 학번과 이름은 저장하지 않습니다.
- AI가 만든 결과는 초안입니다. 과학 내용은 교과서와 견주어 확인하세요.
- 단원명은 2022 개정 교육과정 기준입니다.
- 다른 서비스의 화면과 단추 이름은 바뀔 수 있습니다.
